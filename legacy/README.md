# Earlier experimental implementation

`openai-backend/` preserves the experimental backend originally bundled with
`EPICLab/visdoc_framework`. Its upstream README directs users to
`visual_doc_demo` for the stable backend, which is now imported at `../backend/`.

Use the [main setup instructions](../README.md) to run VisDoc. This directory
is retained for provenance and inspection, not as a second required service.
