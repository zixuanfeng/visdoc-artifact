# VisDoc frontend

This directory contains the React interface imported from
`EPICLab/visdoc_framework/visdoc_react`.

For the combined backend/frontend setup, use the [main README](../README.md).
Start the main backend from `../backend/`, then run `npm ci` and `npm start`
inside this directory. The interface expects the backend at
`http://127.0.0.1:8080`.

The original Create React App README is preserved in
[docs/upstream/](../docs/upstream/frontend-create-react-app-readme.md).
