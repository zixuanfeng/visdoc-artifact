# VisDoc backend and research pipeline

This directory contains the application, research utilities, data files, and
saved outputs imported from `EPICLab/visual_doc_demo`.

Use the [main README](../README.md) for the combined setup. Run `python app.py`
from this directory after installing dependencies and setting the API variables.
The Flask server uses port 8080; its React frontend is in `../frontend/`.

The original repository contained both `README.md` and `readme.md`. Their
contents are preserved separately in [docs/upstream/](../docs/upstream/) so this
release can be checked out on case-insensitive filesystems.
